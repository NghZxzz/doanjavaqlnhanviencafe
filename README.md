# ☕ Coffee Shop Human Resource Management System

## 🚀 Introduction
The **Coffee Shop Human Resource Management System** is a web-based application built with **Java Spring Boot**.  
It helps coffee shop owners and managers efficiently manage employees, work shifts, rewards & discipline, and salary calculation based on the number of worked shifts.  

With **Spring Security** for authentication and **Thymeleaf + Bootstrap** for a responsive UI, the system provides a secure and user-friendly solution tailored to the coffee shop business.

---

## 🛠 Technology Stack

| Technology                  | Purpose                                     |
|-----------------------------|---------------------------------------------|
| **Java + Spring Boot**      | Backend framework for application logic     |
| **Spring Data JPA (Hibernate)** | ORM for database interaction          |
| **Spring Security**         | Authentication & Authorization              |
| **Thymeleaf**               | Server-side template engine for UI          |
| **MySQL**                   | Relational database management              |
| **Bootstrap**               | Responsive UI design                        |

---

## ✨ Features

### 🔹 Common Features (Employees & Admins)
- 🔑 **Authentication**: Secure login/logout with role-based access.  
- 👤 **Profile Management**: View and update personal employee information.  
- 🎭 **Role-Based Dashboard**: Redirect employees and admins to separate dashboards.  

### 🔹 Admin Features
- 🛠 **Employee Management**: Add, edit, search, and deactivate/reactivate employees.  
- 📅 **Shift Management**: Create, edit, and assign employee shifts; view schedules.  
- 🏆 **Reward & Discipline**: Manage employee rewards and disciplinary actions.  
- 💰 **Salary Management**: Calculate salaries based on shifts worked and adjust with rewards/penalties.  

### 🔹 Employee Features
- 📅 View assigned work shifts.  
- 💰 Track salary details based on worked shifts.  
- 🏆 View personal rewards and disciplinary records.
